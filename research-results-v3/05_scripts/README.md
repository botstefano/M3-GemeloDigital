# Scripts de análisis

`recalcular_constancia.py` vuelve a calcular las estadísticas y figuras asociadas únicamente al conjunto de 14 surveys SAG de Constancia. No ejecuta, modifica ni calibra el motor M-3.

Entorno probado y dependencias fijadas en `requirements.txt`. Ejecución desde la raíz del depósito:

```powershell
py -m pip install -r .\05_scripts\requirements.txt
py .\05_scripts\recalcular_constancia.py
```
