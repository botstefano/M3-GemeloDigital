# Datos externos SAG de Constancia

La transcripción de 14 surveys de la Tabla 13-2 está en `constancia_sag_table_13_2.csv`. La fuente y las definiciones de las variables constan en `FUENTE_Y_NOTAS.md`.

El script de recálculo crea `resultados_recalculados/` con estadísticas descriptivas, métricas de comparación, correlaciones, resultados exploratorios por tipo de mena y resumen por fecha.

No se afirma que estos datos representen la operación simulada por M-3. Son exclusivamente un conjunto externo para contraste descriptivo.
